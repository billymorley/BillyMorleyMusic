# Billy Morley website - photo pass

This version keeps the existing copy and adds a first visual layout using the supplied photography.

## Included in this pass

- Responsive photographic homepage hero
- Photographic page heroes for About, Session Guitar, Media and EPK
- Career, broadcast, ensemble and award imagery placed in relevant sections
- A new still-photography gallery on the Media page
- The existing Spotify playlist embedded on the Media page
- Logo files copied into `assets/logos/`, matching the paths already used in the HTML
- Web-optimised WebP versions of the selected photographs
